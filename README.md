# Expense Bot — семейный учёт расходов в Telegram

Телеграм-бот для учёта семейных расходов на двух человек. Пишешь в чат
`Кофе 300`, выбираешь категорию кнопкой — запись уходит в SQLite. Дальше отчёты
за месяц, графики, лимит бюджета, регулярные расходы, цели накопления и
распознавание чеков по фотографии.

Весь бот — один файл `expense_bot.py`, хранилище — обычная база SQLite.
Зависимостей минимум, сервер не нужен: хватит любой машины с Python.

## Возможности

- **Внесение расхода одной строкой**: `название сумма`, категория выбирается кнопкой
- **Свои категории** — добавить и удалить прямо из чата
- **Отчёты** за текущий и прошлый месяц с хронологией; если отчёт не влезает
  в сообщение, он уходит CSV-файлом
- **Статистика** за месяц: общая сумма, разбивка по членам семьи, последние операции
- **Месячный лимит бюджета**: предупреждение, когда осталось меньше 20%, и алерт
  при превышении
- **Распознавание чеков по фото** — бот достаёт из фотографии название и сумму
- **Регулярные расходы**: сохранённый шаблон добавляется одним нажатием
- **Редактирование и удаление** последних записей
- **Диаграмма расходов по категориям** за месяц или произвольный период
- **Цели накопления** с прогресс-баром
- **Еженедельная сводка** по воскресеньям
- **Уведомления в семейный чат** о каждом новом расходе (опционально)

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и краткая инструкция |
| `/stats` | Статистика за текущий месяц |
| `/recent` | Последние 10 расходов, с кнопками правки и удаления |
| `/report` | Отчёт за текущий или прошлый месяц |
| `/chart` | Диаграмма расходов по категориям |
| `/categories` | Свои категории: просмотр и удаление |
| `/setlimit` | Установить месячный лимит: `/setlimit 50000` |
| `/regular` | Регулярные расходы: добавить, применить, удалить |
| `/goals` | Цели накопления |
| `/addgoal` | Создать цель: `/addgoal Отпуск 150000` |
| `/contribute` | Пополнить цель: `/contribute Отпуск 5000` |
| `/diag` | Самодиагностика распознавания чеков |
| `/models` | Список доступных моделей |
| `/help` | Справка |

Доступ ограничен списком `ALLOWED_USER_IDS` — посторонний получит «Доступ запрещен».

## Установка

Нужен Python 3.10 или новее.

```bash
git clone https://github.com/russoroma873420-hash/expense-bot.git
cd expense-bot

python3 -m venv bot-env
bot-env/bin/pip install -r requirements.txt

export TELEGRAM_BOT_TOKEN="токен от @BotFather"
bot-env/bin/python expense_bot.py
```

База `expenses.db` создастся сама при первом запуске и будет лежать рядом со скриптом.

### Переменные окружения

| Переменная | Обязательна | Зачем |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | токен бота от [@BotFather](https://t.me/BotFather); без него бот не стартует |
| `DEEPSEEK_API_KEY` | нет | только для распознавания чеков по фото ([platform.deepseek.com](https://platform.deepseek.com/api_keys)); без него остальное работает |

Секреты читаются только из окружения и не хранятся в коде — так токен не попадает
в историю git.

### Автозапуск через systemd

```ini
[Unit]
Description=Telegram family expense bot
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=expense
WorkingDirectory=/opt/expense-bot
EnvironmentFile=/opt/expense-bot/expense-bot.env
ExecStart=/opt/expense-bot/bot-env/bin/python /opt/expense-bot/expense_bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Файл окружения держите с правами `600`:

```bash
# /opt/expense-bot/expense-bot.env
TELEGRAM_BOT_TOKEN=...
DEEPSEEK_API_KEY=...
```

## Настройка под себя

Всё в начале `expense_bot.py`:

| Параметр | Значение по умолчанию | Что делает |
|---|---|---|
| `ALLOWED_USER_IDS` | два ID | кому разрешено пользоваться ботом |
| `USER_NAMES` | имена по ID | как подписывать записи в отчётах |
| `CATEGORIES` | 10 категорий | стартовый набор категорий |
| `LOCAL_TZ` | `Asia/Barnaul` | часовой пояс: по нему считаются дни, месяцы и время сводки |
| `FAMILY_CHAT_ID` | `None` | чат для уведомлений о новых расходах |

Часовой пояс влияет на даты записей и на время еженедельной сводки (19:00 по
`LOCAL_TZ`). Поменяйте на свой город — например, `Europe/Moscow` или `Asia/Krasnoyarsk`.


к Telegram. Покрывают запись и правку расходов, категории, цели, лимит, отчёты и
CSV, разбор ввода, белый список, экранирование, расписание сводки и формат
хранения времени.

## Безопасность

- Токен бота и ключ DeepSeek — только в переменных окружения или в файле окружения
  с правами `600`; в репозиторий они не попадают
- `*.db` в `.gitignore`: база с расходами тоже не должна уезжать в git
- Если токен всё же попал в историю коммитов — отзовите его в @BotFather через
  `/revoke`: он останется доступен всем, у кого есть копия репозитория
